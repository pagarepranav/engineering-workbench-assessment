REVIEWER WALKTHROUGH

A clear path through the project.

Everything runs locally. No AI API key is needed.

01

Try the application

Create a short URL, open it in a new tab, then view analytics. Try a duplicate alias, an expired link, or a disabled link.

02

Run an authored demo

Select Greenfield or Brownfield in demonstration mode. Inspect the staged Java files and baseline changes. Review and explicitly approve local code execution.

03

Review real validation

The tool runs javac and CandidateTest in a candidate workspace. Compilation errors and assertion failures are real. Two repair opportunities precede a safe stop.

04

Use ChatGPT manually

Create a manual run. Copy each prompt to ChatGPT. Import JSON for analysis, planning, and implementation. Resolve questions through the clarification field.

05

Inspect governance

Stop and resume a run, reject an approval, or revise the requirement. Each approval covers a specific revision and SHA-256 hash. Old revisions remain available in the evidence export.

06

Know the boundaries

Generated code executes with your local OS permissions after review. It is not OS sandboxed. Candidate releases are local file artifacts, not a production deployment. Hash chains are not externally anchored.

Submission scope

Java / Spring Boot · persistent H2 storage · optional PostgreSQL profile · manual AI handoff · JDK-only candidate service · no cloud account required. See README and docs for setup, architecture, tests, and limitations.
